# 鈴木さん専用｜Instagramリールのトレース

版 3.0（2026-11-15）。鈴木さんの支援に限って使う。案件の[入口](../../README.md)で対象の制作フォルダを確認し、その中の work/ に編集元・素材、outputs/ に完成物を保存する。

自社撮影なしで、人物・店舗・倉庫を含めた元動画の全編再現を目指す。範囲の指定があればそれに従う。「全て」は合意した対象リストの各投稿について、冒頭から締めまでを制作する。アカウントの調査母数、選定した本数、実際に完成した本数を記録する。

## 鈴木さんへ渡す実行キット

Mac対応実行キットv1.7は、今回の梱包レシピに限り、初回セットアップとMiniMax APIキー・利用残高があれば画面から生成・編集・比較書き出しを実行できる。別動画はAIが参考の全編を分析して新しいレシピを作る。v1.4から、参考動画の取得と文字起こしの道具を初回セットアップで導入し、`engine/media.py` から使える（課金なし）。鈴木さんはMac利用。Appleシリコンは推定のため起動時に実機のチップ・OSを判定する。Mac実機検証とWindowsでの代替検証を区別する。[配布キットの仕様と作り方](references/portable-kit.md)を読み、同梱の梱包専用の除去座標・字幕・音声処理を別動画へそのまま流用しない。

2名以上なら、人物ごとの参照画像と役割を用意する。全区間で同じ順序・人物対応を維持し、元動画は動作・構図の参考、指定画像は顔・髪・服装の参考として分ける。画像指定は完全一致の保証ではなく、生成後に取り違えや混合を確認する。

## 再現の優先順位（2026-11-13更新）

目的は元動画の再現。元にない商品パネル、補足画像、独自の見せ場は加えない。商品画像は、元動画にも商品画像が表示される場面の位置・大きさ・動き・時刻に合わせて使う。手に持っている商品を、別枠の商品画像で補足して再現済み扱いにしない。

人物・倉庫・手持ち動作は、指定人物画像や元動画を参照した生成をまず試す。元が手持ちなら手持ちを維持する。生成上の細かな完全一致は出力後に比較して確認し、未達点を明記する。人物を商品画像に置き換える旧方式は、その方式が明示指定された場合の代替とする。

### カード・商品画像が映る場面（2026-11-14追加）

元動画にカードや商品の画像が重ねて表示される場面は、**参考の元映像を試作に流用せず、公式の商品画像を元と同じ位置・大きさ・時刻・動きで合成する**。元映像を切り出す、ぼかして下に敷く、上半分だけ残すといった使い方も流用に含む。比較用の試作にも適用する。背景は生成した映像か新規に作った背景を使う。

画像は、指定された素材フォルダ・素材台帳、次にメーカーや公式の商品ページから取得し、取得元のURLと取得日を、制作ブリーフと素材フォルダの出典記録（例：assets/sources.json）の両方に記録する。該当の絵柄を公式資料で確認できないときは、その商品の画像だけを依頼者に求める。黙って元映像で代用しない。画像が届くまで進める場合は、対象弾のBOXを見せて名前を文字で示し、未達として比較ページに明記する。

比較画面の「参考」側は原資料なので元映像のままでよい。人物・倉庫・手持ちの場面を生成で再現する方針は変わらない。2026-11-14の通し試験では、指示が曖昧だったためCodexがカード場面約6秒に元映像を使った。その版は試験記録であり、手本にしない。

### 字幕と顔・商品名の重なり（2026-11-15追加）

字幕や画面の文字は、**人物の顔と商品名・カード名にかぶせない**。字幕は編集で載せるので、場面ごとに置く場所・大きさ・行数を変えてよい。顔が画面の上側にある場面は下側へ、顔が中央にある場面は上か下の空いている側へ置く。参考動画の字幕位置が顔や商品名に重なる場面は、参考の位置より重ならないことを優先する。依頼者が字幕の位置を指定したときはその指定に従う。

人物が大きく動く場面は、顔が通らない端に固定するか、その場面だけ字幕を短くする。顔のアップで避けきれない場面は、あごの下か画面の端に小さく置き、未達として比較ページに明記する。完成後は1秒ごとの静止画で全編の重なりを確認し、重なっていれば字幕の編集だけを直す。映像の作り直し（追加の費用）はしない。

EB-05の公式BOX別枠表示版はユーザーが不採用とした。追加表示前の人物差し替え版を現在の比較基準にする。2026-11-12の共有ZIPは版2.2の配布スナップショット。新規制作には正本版3.0と現在の使い方を使い、再配布する際も正本を渡す。

## 店名・ロゴ・話す内容の指定（制作前）

参考の構図・動き・テンポと、制作する店の情報を分ける。生成・音声収録の前に、既存の合意と依頼文から次を制作ブリーフへ記録する。記入用の依頼文は[利用ガイド](references/usage.md#そのまま使える依頼文)にある。

| 項目 | 指定がある場合 | 指定がない場合 |
|---|---|---|
| 店名・英語表記・読み方 | 指定表記を発話・字幕・締めに統一 | 店名を表示・発話しない。競合名を引き継がず、自社名も創作しない |
| ロゴ素材・位置・表示する場面 | 提供ロゴを使用。位置未指定なら元のロゴ位置を目安にする | ロゴ表示なし。参考元の侍のロゴを代用しない |
| 話す内容・必ず入れる／削る表現 | 指定台本を優先し、英語音声・英語字幕・日本語訳を同じ意味にする | 商品説明の訴求・順序を基準に、競合の店名や店舗固有の案内を除いた台本にする |
| 所在地・在庫・価格・発送条件・誘導先 | 依頼者の確認済み情報を使用 | 競合の条件を自社の事実として転用しない。必要な事実だけまとめて確認し、不要な固有案内は省く |

**明示的な保持指定がなければ、Samurai Sword Tokyo／侍など参考元の店名・ロゴを試作に残さない。比較用の試作にも適用する。「元動画を再現して」「全編をトレースして」だけでは保持指定とみなさない。** 店名の読み上げ、字幕、透かし、店のスローガン、看板、アカウント名、URL・QR、締め画面も対象。商品本来のパッケージやメーカーのロゴまで消すルールではない。

元・変更後の発話と字幕を場面ごとに対応付け、何を変更・省略したか記録する。店名の締めを省く場合も全編の尺・流れを保ち、元にある商品・背景の映像や店名なしの締めにする。元にない補足商品パネルは追加しない。既知の指定やこの既定値で進め、毎回の承認待ちは設けない。制作に必要な重要事実だけが不明なら、その箇所の生成前に確認する。

生成プロンプトと音声台本から参考店の固有情報を除く。参照映像から文字・ロゴが再出現することがあるため、除去・差し替えを生成指示だけで完了扱いにしない。正確なロゴや字幕は編集で合成する方法を優先し、焼き込まれた元ロゴ・文字は修正してから載せる。

比較画面の「参考」側の元動画・元音声と出典は原資料として保持できる。「試作」側、単体動画、試作の表紙・対訳には未指定の競合ブランドを残さない。過去の納品動画は新ルール対応済みと扱わず、変更依頼があれば別版として改訂する。

## 参考動画を受け取ったとき

初回の使い方は[利用ガイド](references/usage.md)を参照する。参考動画のファイル、または個別投稿URLを入口にする。URLを受け取ったら映像と音声を取得・確認できるか調べ、取得できなければ動画ファイルの提供を求める。投稿文や表紙だけで全編を分析した扱いにしない。

商品が参考と同じなら、その映像・投稿文から型番を照合し、利用可能な素材台帳や公式商品資料を先に探す。台帳の場所や接続は設定済みと推測しない。別商品に変える場合は対象商品を確認する。特定カードの絵柄や自社の販売条件が不明な場合は、その不足だけをまとめて確認する。比較用でも試作には上記の店名・ロゴ・台本の既定値を適用する。参考側の競合情報は投稿当時のものと表示する。用途未指定なら比較用試作として扱い、自社公開用の事実確認が済んだことにはしない。

別のPC・AI環境では、参考映像を読む手段、商品画像の入手経路、英語男性音声の生成、映像・字幕・音の合成とMP4書き出し、最終比較の確認が可能か先に確認する。スキル単体は作業指示。Mac対応実行キットv1.7には、梱包の生成・編集プログラムに加えて、動画の取得（`engine/media.py fetch`）と文字起こし（`engine/media.py transcribe`）を同梱する。台本の作成、英語ナレーションの生成、仕上げの編集は動画ごとにAIが準備する。英語ナレーションは、2026-11-14の通し試験でMiniMaxの音声APIを同じキーで使えた（約24秒の語りで約6円）。鈴木さんのキーでの利用可否は未確認。既存10本の制作成功と、新環境での再制作成功を区別する。不足があれば具体的な設定や素材を示し、可能な分析・台本作成を先に進める。

## 費用の目安（2026-11-14追加）

別の参考動画を1本作る目安は約400〜1,000円（MiniMaxの映像・音声の利用料。1ドル159.2円の固定換算、税・決済手数料・AIの契約料金は別）。根拠は3件：約24秒の語りあり動画で、作り直しなし約400円（2026-11-15）と、見積り約615円・作り直し1回込み約955円（2026-11-14）。約35秒の梱包動画で約892円。参考動画を入力する秒数にも料金がかかる。尺が長いほど、作り直すほど増える。

見積りを先に示し、依頼者が決めた上限の中で発注する。作り直しは上限内で1回までを目安にし、超える場合は理由を伝えて止める。この金額は目安であり、上限や完成の保証ではない。

## 映像とセリフの設計

- 元動画を最後まで確認し、元の時刻、映像、発話、画面上だけの文字、画面が伝えることを書き出す。カットと字幕は別々に変わる。倉庫に切り替わる時刻、視聴者コメント、小さな在庫条件、最後の購入・フォロー案内や店名まで拾う。
- 制作前の指定・競合情報の除去が必要な箇所を除き、台本は元の主語、時制、数字、問いかけ、否定、確度、順序を保つ。「未受付だが予定あり」「予約終了、通常販売はこれから」「取り扱うか未定」を区別する。資料や映像が足りないときに、別の買い物アドバイスへ置き換えると訴求まで変わる。
- 商品画像への置き換えを明示指定された場合に、人物、棚、倉庫、手元、店の画面などを使えないときは、その瞬間に話しているカード・BOX・パック・特典を素材台帳や公式資料から選ぶ。該当の絵柄を確認できない場合は、対象弾のBOXを見せ、レアリティやキャラクター名は文字で示す。外観や別絵柄で特定カード、実在庫、傷、開封結果を証明したように見せない。
- 商品画像への置き換え方式で、店舗固有の内容も保持する明示指定がある場合、例えば、倉庫の場面で「国内発売に向けて商品を確保する準備中」と話していれば、該当BOXを少しずつ寄せて同じ内容を語る。「予約はいつ？」の箇所は商品に質問を重ね、「このアカウントで受付を告知」ではカードからBOXへ切り替える。動きは元のカットの長さ・向き・強さに合わせ、同一カット内の字幕変更ごとに商品をリセットしない。
- 社内比較・自社公開版とも、試作側の店名・ロゴ・発話は制作前の指定と既定値に従う。参考側の当時の告知と試作側の変更後の内容・日本語訳を分け、意味の変更を比較画面に残す。
- 元投稿がセールポスター等で語りのない場合、画像内の期限・数量・購入方法が台本になる。ナレーションの指定があれば読める長さにまとめる。販売条件は制作先の確認済みの情報に合わせ、未確認の競合条件は転用しない。

## 音と仕上げ

原稿は意味がつながる文または段落単位で読み、実際の発音位置に字幕を合わせる。今回の基準は抑揚のある明るい英語男性声。字幕ごとに音声を切ると文中が途切れる。商品名の読みを登録し、最後の単語まで書き出す。参考のカット・強調位置に合わせてBGMとSEを配置し、語りを聞き取れる音量にする。画面の動き、発話、字幕、効果音を最終MP4で照合する。全編の映像・字幕・音声を確認し、未指定の競合店名・ロゴ・締めの読み上げが残っていないかを検品する。修正できない残りは明示し、除去済みとして納品しない。

## 納品と確認

試作単体の縦型MP4を用意する。比較は左に元動画、右に試作を同期表示し、同じ再生位置で音声を切り替えられるようにする。複数本では表紙から各投稿の全編を直接開く。元・試作の字幕の日本語訳、画面だけに出る文言、元投稿へのリンク、使った代替素材と意味の差を載せる。聞き取りから復元した参考文はその旨を表示する。

書き出した全ファイルの映像・音声尺を元尺と照合し、端数は最大1フレーム程度に収める。各作品の人物・倉庫の置き換え、数字と予約条件、字幕の可読性、終端と音声切り替えを確認する。比較の簡易版には同梱の `scripts/make_review.py` と `scripts/review.html` を使える。

```sh
python scripts/make_review.py reference.mp4 trial.mp4 review.html --start 0 --duration 31.36 --title "OP-17 全編比較"
```

上記の秒数は例。対象リールの実尺に合わせる。
