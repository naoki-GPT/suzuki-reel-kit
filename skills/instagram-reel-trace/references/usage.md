# 鈴木さん｜参考動画からリールを作る使い方

版 1.7 ／ 2026-11-15（スキル版3.0対応）

変更点：実行キットv1.5に合わせ、費用の目安を約400〜1,000円に改めました。参考動画の取得は、失敗しても自動で数回やり直します。カード画像の場面の作り方と、初回の準備で動画の取得と文字起こしの道具が入る点は前の版と同じです。制作前の店名・ロゴ・台本指定を継続。未指定の競合ブランドは試作に残さず、人物・倉庫は元の構図や動きを生成して再現します。

初回はキットの「はじめに.html」の3ステップに従います。Codexデスクトップでsuzuki-reel-kitを開き、「最初にCodexへ.txt」を貼ってセットアップを依頼。APIキーは画面の「キーを保存」で.envへ保存します。次回から人物画像＋参考URL＋「動画を作る依頼文.txt」で制作を依頼します。

## 費用の目安

別の参考動画を1本作ると、MiniMaxの利用料は約400〜1,000円が目安です。約24秒の動画では、作り直しなしで約400円の回と、見積り約615円・作り直し1回を含めて約955円の回がありました。約35秒の梱包動画は約892円でした。動画が長いほど、作り直すほど増えます。AIが先に見積りを出すので、上限の金額を伝えてから始めてください。税・決済手数料・AIの契約料金は別です。

## 基本の使い方

参考動画を渡して「この動画を、鈴木さん専用スキルで、自社撮影なしのリールにしてください」と依頼する形で始められます。対象は個別リールのURLか動画ファイルです。アカウント全体を渡す場合は、選定する本数も指定します。

依頼後はAIが参考の分析、素材の選定、台本、音声・字幕・演出、比較画面まで順に制作します。人物や倉庫も元の構図・動きに寄せて生成し、指定人物があれば使います。元にない商品パネルは追加しません。カードや商品の画像が映る場面は、参考の映像をそのまま使わず、公式の商品画像を同じ位置に合成します。公式の画像が見つからないカードだけ、画像をお願いすることがあります。商品画像への置き換え方式は、その方式を指定した場合に使います。

今回の梱包動画は、Mac対応実行キットv1.2に素材・生成指示・操作画面を同梱しています。キットの「はじめに.html」を開き、Macでは01_setup.command → 02_start.command → APIキー保存 → 見積り → 制作開始で進められます。人物2名の画像を選択でき、途中再開と比較書き出しに対応します。

任意のURLから完成までの一括自動分析は含まれません。別動画はこのスキルをAIに読ませ、全編分析と新しい制作レシピの準備を依頼します。[キットの技術手順](portable-kit.md)を参照してください。

## はじめて使うとき

1. 2026-11-12の共有ZIPは旧スキル版2.2の保管版です。新規制作にはこの使い方とスキル正本版3.0を使い、共有する際も正本のスキルフォルダと使い方を渡してください。過去の比較動画を見る場合は共有ZIPをすべて解凍し、「はじめに.html」を開きます。既存の比較動画は、パソコンのブラウザだけで確認できます。Mac対応実行キットv1.2では今回の2名指定版を完成例として同梱しています。
2. 制作するAIの作業フォルダに、現在の案件フォルダにある skills/instagram-reel-trace/ フォルダを丸ごと置きます。フォルダやファイルを読み、動画の処理や書き出しを実行できるAI環境が必要です。
3. AIに「skills/instagram-reel-trace/SKILL.md を読んで、必要な制作環境を確認してください」と依頼します。フォルダを読めない環境では、手順書を添付して相談できますが、相談だけで動画書き出しまで可能になるわけではありません。
4. 商品画像のフォルダ、または素材台帳のURLがあれば渡します。スプレッドシートはAIから閲覧できる状態が必要です。今回の共有セットには、素材台帳への接続設定は入っていません。
5. 下の依頼文に参考動画を添えて、まず1本を制作します。別PCでの制作環境は未検証です。担当AIが不足する機能を確認したら、その設定だけ行います。

初回に確認する機能は、動画の読み取り、商品画像の取得、英語音声の生成、映像・字幕・BGM・SEの合成、MP4書き出しです。旧2026-11-12の共有セットには実行環境を含めていません。Mac対応実行キットv1.5には今回の梱包の編集元とセットアップ・生成処理を同梱します。音声モデル・認証情報は含めません。別動画の語りや取得経路は担当AIが確認します。

## 毎回渡すもの

| 渡すもの | 必要になるとき |
|---|---|
| 個別投稿URL、または参考動画ファイル | 毎回。URLから見られない場合は動画ファイルを渡します |
| 対象の商品名・型番 | 参考と別の商品に変える場合、または映像から特定できない場合 |
| 商品画像・素材台帳 | あれば渡します。なければ公式資料などから探し、見つからない商品だけ相談します |
| 店名・英語表記・読み方 | 表示・読み上げたい場合。未指定なら店名なし |
| ロゴ画像・表示位置・場面 | 表示したい場合。未指定ならロゴなし |
| 話す内容・必ず入れる／削る表現 | 原稿は日本語でも可。未指定なら商品説明を基準に競合固有の案内を除きます |
| 人物画像・声の希望 | 指定人物・声を使う場合。過去に指定済みならその旨を記入 |
| 自社の所在地・予約・在庫・価格・発送条件・誘導先 | 動画に含める場合。比較用でも競合の条件を自社の事実として使いません |

通常の基準は、全編・縦型動画・明るく抑揚のある英語男性声・英語字幕・BGM・効果音です。比較画面には字幕の日本語訳を付けます。声や尺を変えたいときだけ追記してください。

## 指定しない場合の扱い

店名・ロゴの指定がなければ、試作に侍／Samurai Sword Tokyoの名前・ロゴを残しません。音声での店名読み上げ、字幕、透かし、店のスローガン、看板、締め画面、アカウントやリンクも対象です。参考元のブランドを残す場合だけ明示してください。「元を再現して」だけでは残しません。商品パッケージ本来のメーカー名・ロゴは別扱いです。

台本が未指定なら、商品説明の順序・訴求を参考にして、競合固有の案内を外します。「東京の自社倉庫」「世界中へ発送」「現在在庫あり」などは推測で入れません。重要な事実が必要な場合だけまとめて確認します。店名を省く締めも、元の尺と流れを保ちます。

比較画面の参考側には元動画・元音声が残ります。試作側の英語・日本語訳は変更後の内容を表示し、参考との違いを記録します。既存動画は旧設定のままで、新ルールに合わせた動画の修正は別の作業です。

## そのまま使える依頼文

```text
鈴木さんのリールを1本作ってください。
skills/instagram-reel-trace/SKILL.md を読み、参考の構図・動き・テンポを冒頭から締めまで再現してください。

参考動画：［個別投稿URL、または動画ファイル］
対象商品：［参考と同じ／別の商品名・型番］
用途：［比較用の試作／自社公開用］
人物：［今回の男性／指定画像／指定なし］
店名・英語表記・読み方：［指定内容／店名なし］
ロゴ：［画像の場所／ロゴなし］
ロゴの位置・場面：［指定内容／元のロゴ位置を目安に］
話す内容：［日本語または英語の原稿／商品説明を参考に作成］
必ず入れる内容・削る内容：［あれば記入］
所在地・在庫・価格・発送条件：［動画で伝えたい確認済みの情報／表示なし］
誘導先：［自社のURL・アカウント／案内なし］
商品素材・台帳：［場所／公式資料などから探してください］

未指定の店名・ロゴは表示・読み上げなしにし、侍の店名・ロゴ・店舗固有の案内は引き継がないでください。
人物や倉庫は元の構図・動きに寄せて生成し、元にない商品パネルは追加しないでください。
英語男性音声・字幕・日本語訳は、指定した話す内容に統一してください。文の途中で音声を切らず、BGM・SEは元の演出に合わせてください。
縦型MP4、参考と試作の同時再生・音声切替、日本語訳、参考から変更した内容の説明まで作成してください。
必要な事実や制作環境が不足する場合だけ、まとめて確認してください。
```

## 依頼後の流れと担当

| 段階 | AIが進めること | 鈴木さん・依頼者がすること |
|---|---|---|
| 1. 受け取り | 動画・商品・用途・制作環境と、店名・ロゴ・台本の指定／既定値を記録 | 参考URLか動画を渡す。取得できない場合だけ動画を追加 |
| 2. 分析 | カット、発話、テロップ、声に出さない文字、音と動きを時刻順に記録 | 通常は追加作業なし |
| 3. 構成・素材選び | 指定人物と元の構図・動きを設計。変更後の台本・字幕・日本語訳と素材を用意 | 特定できない商品や、自社の販売条件だけ回答 |
| 4. 制作 | 指定内容の映像・英語音声を生成し、字幕・ロゴ・BGM・SEを編集 | 通常は追加作業なし |
| 5. 検品・納品 | 全編の音声・字幕・数字・尺に加え、未指定の競合店名・ロゴの残留を確認。比較画面を作る | 比較を見て、必要な修正を伝える |

各段階で毎回承認を求める運用ではありません。決まっている条件で進め、不足する重要情報だけ確認します。投稿・送信はこの制作依頼に含まれません。

## 完成後の見方と修正の頼み方

カタログで作品を開くと、左が参考、右が試作です。試作の音声で発話と字幕を確認し、参考側の音声に切り替えてテンポを比較します。日本語訳で訴求や数字、予約条件を確認できます。

修正は「OP-17の17秒から23秒、BOXの動きをもう少し強く」「12秒の字幕と発話を合わせて」「自社では予約受付中なので、終盤の案内を変更」のように、作品・秒数・変更内容を伝えてください。

確認済みなのは、既存10本の動画と比較カタログの動作です。新しい参考動画の取得可否、素材台帳への接続、別PCでの音声・映像生成は、新規制作時に確認します。
