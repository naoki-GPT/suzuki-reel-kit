## できること

- 今回の約35秒の梱包レシピを、同梱の2名または選択した人物画像で再生成。
- 費用の無料見積り、日次上限（初期2,000円）、制作ごとの上限（梱包は1,200円）。設定額はツール内のガードであり、MiniMaxアカウント全体の利用額上限ではありません。
- 注文番号を保存して途中から再開。通信の成否が不明な注文を自動で再発注しない。
- 生成済み映像から字幕・BGM・SE・比較ページ・閲覧用ZIPを再編集。再編集はAPIへ発注しません。
- 完成例をAPIキーなしで閲覧。

## 別の参考動画を作る場合

**費用の目安は1本あたり約400〜1,000円です**（MiniMaxの利用料）。約24秒の語りあり動画は、作り直しなしで約400円の回と、見積り約615円・作り直し1回を含めて約955円の回がありました。梱包動画（約35秒）は約892円でした。動画が長いほど、作り直すほど増えます。AIが出す見積りを見て、上限の金額を伝えてから始めてください。税・決済手数料・Codexなどの契約料金は別です。

**URLを入れるだけの自動分析アプリではありません。** Codex等の、ローカルファイル・動画を読んで処理できるAIへ、このフォルダと参考URLまたは動画ファイルを渡します。`AIへの依頼文.txt`と `skills/instagram-reel-trace/SKILL.md` を入口に、別動画用の生成指示・区間割り・字幕・音声・編集スクリプトを作ります。完成した `project.json` を操作画面で選べます。

URLからの動画の取得と文字起こしは、同梱の道具（`engine/media.py`）で行えます。どちらも課金はありません。Instagram側の都合で取得できない投稿は、動画ファイルを渡してください。

今回の梱包は語りのない動画です。別動画の台本・英語ナレーション・ロゴ合成・仕上げの編集は、担当AIが動画ごとに用意します。カードや商品の画像が映る場面は、参考の映像を使わず公式の商品画像を合成します。公式の画像が見つからないカードは、画像をお願いすることがあります。MiniMax以外のサービスを使う場合は、その設定・費用が別途必要になることがあります。

店名・ロゴ・話す内容は `制作依頼テンプレート.md` で制作前に指定。未指定なら参考店の名前・ロゴを試作に残さず、競合の所在地・在庫・発送条件を自社の事実にしません。

## 保存先

- `projects/packing/`：今回の梱包の制作レシピ。
- `projects/custom_.../`：画面で人物画像を変更したときの別レシピ。元は保持。
- `runs/日時_packing/`：各回の素材スナップショット、注文番号、動画、確認結果。
- `runs/日時_packing/work/outputs/index.html`：完成した比較画面。
- `examples/packing/`：2026-11-13の完成例。生成結果は毎回変わります。
- `.env`：鈴木さんが入力したAPIキー。共有禁止。配布ZIPには含まれません。
- `.models/`：文字起こし用データ。初回の準備で取得。配布ZIPには含まれません。

途中停止後は「途中から再開」。新しい画像・指示で作り直すときは「制作を開始」で新しい制作回を作ります。再開は開始時の素材を使い、画面で後から選んだ画像は反映しません。過去の制作回を再開する場合は `engine/run.py resume --run runs/対象フォルダ`。

## 検証の範囲

今回の2名版はMiniMax H3で3区間の実生成を確認済み。このキット自体の新規注文は再課金を避けて模擬通信で検証しました。新しい専用Python環境で依存ソフトを導入し、実生成済みの映像を使って移動先フォルダで編集・比較出力を確認済みです。Mac用スクリプトの構文・環境判定、同梱フォントを使った再編集は確認しました。ただしMac実機でのインストール・画面表示・書き出しと、鈴木さんのAPIキーでのH3利用は未確認です。機能ごとの結果は `検証結果.json` を参照してください。

使用中のフォルダを丸ごと他人へ渡すと、後から保存したキーや注文履歴も含まれます。共有には最初の配布ZIPを使用してください。

## Macで最初に開くファイル

1. ZIPをダブルクリックして展開し、フォルダ全体を「書類」などへ置きます。
2. `01_setup.command` を開き、初回の準備をします。Homebrew未導入なら公式インストーラーの確認が出ます。Macのログインパスワードを求められる場合があります。
3. `02_start.command` を開きます。次回以降はこのファイルだけで起動します。
4. APIキーを保存 → 人物画像を確認 → 無料見積り → 制作開始。

実行権限のエラーの場合は「ターミナル」を開き、`/bin/bash `（末尾に半角スペース）を入力し、対象の.commandファイルをその後へドラッグしてEnter。安全性の確認で止まる場合は、内容と入手元を確認してからApple公式の「プライバシーとセキュリティ → このまま開く」を参照してください。Mac全体の保護機能を無効にする必要はありません。

Windowsでは `01_setup.bat` → `02_start.bat` を使用します。MacとWindowsの専用環境は別に作成されます。字幕は両OSで使えるArimoフォントを同梱しています。以前の完成例は元の字幕フォントのまま保管しています。
